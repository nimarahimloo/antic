# تصاویر محلی (مهاجرت از CDN)

این پوشه تصاویر استاتیک UI است که قبلاً از media.base44.com سرو می‌شدند.

در **runtime** هیچ درخواستی به Base44/Wix زده نمی‌شود؛ فقط فایل‌های همین پوشه.

## پر کردن پوشه

از ریشهٔ پروژه:

```bash
node scripts/migrate-images.mjs
```

یا آرشیو تصاویر مهاجرت‌شده را اینجا extract کنید.
